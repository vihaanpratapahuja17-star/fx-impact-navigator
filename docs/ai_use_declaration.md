# AI use declaration

Generative AI was used to assist with project scaffolding, drafting modular Python code, suggesting calculation and validation cases, writing documentation, and debugging implementation issues. The generated code and prose should be reviewed by the student group before submission.

The group must independently understand and be able to explain the return definition, volatility convention, VaR/CVaR tail convention, transaction sign rules, scenario assumptions, hedge calculation, and data limitations. The group should run the application on its own sourced data and on the evaluator's live validation dataset, interpret those results itself, and record any changes made after review. AI-generated material does not substitute for the group's modeling decisions, interpretation, or viva defense.
